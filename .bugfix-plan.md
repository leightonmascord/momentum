# Momentum Bug Fix Plan

Audit produced the following enumeration. Each item gets fixed in order, with the verification step noted.

## CRITICAL

### C1 — Pomodoro phase-transition effect re-fires and saves a phantom session
**Files:** `src/components/widgets/PomodoroTimer.tsx`
**Symptoms:** Phase-change handler saves a focus session even when nothing was actually studied (or any other phantom on every transition).
**Fix:**
- Track previous phase + previous `pomStartedAt` in refs.
- The tick handler that decides a phase has elapsed reads `pomStartedAt` once and acts only on real elapsed time.
- Re-entrancy guard: if the previous render's phase is still 'focus' and the elapsed exceeds `focusMinutes`, transition ONCE; clear/reset only on a new explicit user action.
- Cleanest: derive tick from wall clock `(Date.now() - pomStartedAt)/1000`, plus a `transitionedRef` that flips when a transition fires so the next tick in the same render commit doesn't re-fire.
- Also clear `pomIntervalRef.current` on every phase change so a stale interval can't race.

**Verify:** Manual scenario in code: if `pomPhase==='focus'`, `startedAt=t0`, `focusMinutes=25`, wall clock now `=t0+25min`, the handler fires ONCE, saves the focus session, sets phase to 'break', and the next interval tick does NOT save another session.

### C2 — QuickTimer seconds inflate academic total
**Files:** `src/lib/timer-utils.ts`
**Symptoms:** QuickTimer running on a non-academic subject still adds minutes to the PomodoroTimer academic total.
**STATUS: FIXED** (2026-08-13) — Dashboard.tsx:663 now calls `getLiveTimerSeconds(data.subjects, data.categories)` so non-academic QuickTimer seconds are excluded from the academic "Today" total.
**Fix:**
- Change `getLiveTimerSeconds` to return `{ seconds, subjectId }`.
- Have `getTotalTodayMinutes` resolve QuickTimer's subject scope via `getSessionScope` and only include the live seconds when both timer sources are academic.
- Update all callers (`Dashboard.tsx`, `PomodoroTimer.tsx`).

**Verify:** A QuickTimer running for a subject whose category is `nonAcademic` does NOT change the dashboard's "Today" total.
